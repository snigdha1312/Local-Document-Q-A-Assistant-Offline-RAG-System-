# 🛡️ Local Document Q&A Assistant (Offline RAG System)

A privacy-first Retrieval-Augmented Generation (RAG) application that allows you to chat with your personal, confidential, or proprietary documents (PDF/DOCX) entirely offline. By leveraging local embeddings and a locally hosted LLM via Ollama, this system guarantees **100% zero data leakage**—no data is ever sent to external APIs like OpenAI or Anthropic.

## ✨ Key Features

* **Absolute Privacy:** Runs entirely on your local hardware. No internet connection required after initial setup.
* **Intelligent Document Parsing:** Custom-built PDF and DOCX parsers that slice documents using a 500-character sliding window with a 50-character overlap to preserve contextual continuity.
* **Fast Semantic Retrieval:** Utilizes a FAISS L2 vector index to store 384-dimensional dense semantic embeddings generated by the highly efficient `all-MiniLM-L6-v2` model.
* **Factual & Grounded Generation:** Powered by `llama3.2:3b` (via Ollama). The model dynamically fetches the top-4 context sources and operates at a strict `0.0` temperature to eliminate hallucinations and force context-reliant answers.
* **Modern UI:** Features a sleek, responsive, dark-themed Streamlit interface for seamless chat sessions and source citation tracking.

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **LLM Engine:** Ollama (`llama3.2:3b`)
* **Embeddings:** HuggingFace (`sentence-transformers/all-MiniLM-L6-v2`)
* **Vector Store:** FAISS (Facebook AI Similarity Search)
* **Document Processing:** PyPDF, python-docx

## ⚙️ Architecture Flow

The RAG pipeline operates as follows:
```
[ Upload Document (.pdf/.docx/.txt) ]
               │
               ▼
[ Text Extraction (pypdf / python-docx) ]
               │
               ▼
[ Sliding Window Chunking (~500 chars, 50 overlap) ]
               │
               ▼
[ Local Embeddings Generation (sentence-transformers: all-MiniLM-L6-v2) ]
               │
               ▼
[ Local Vector Indexing (FAISS L2 Flat Index) ]
               │
   ┌───────────┴───────────┐
   ▼                       ▼
[ User Query ] ──► [ FAISS Semantic Search (Top K Chunks) ]
                           │
                           ▼
             [ Strict Local System Prompt Formulation ]
                           │
                           ▼
             [ Local Inference (Ollama: llama3.2:3b) ]
                           │
                           ▼
             [ Answer Generation + Source Citation ]
```

## 🚀 Quick Start Guide

### Prerequisites
1. **Ollama**: Download and install Ollama for your operating system: [https://ollama.com/download](https://ollama.com/download)
2. **Python**: Version 3.9 or higher.

### 1. Setup the Local LLM
Start the Ollama application or service, then run the following in your terminal to download the default model:
```bash
ollama pull llama3.2:3b
```

### 2. Install Python Dependencies
Install the required packages using the offline-friendly, no-cache flag:
```bash
pip install --no-cache-dir -r requirements.txt
```

### 3. Cache the Embeddings Model
Run the test script once while connected to the internet to download and cache the local sentence-transformer weights (`all-MiniLM-L6-v2`):
```bash
python3 test_embed_store.py
```
After this initial download, the model will run completely offline.

---

## 🚀 Running the Application

1. Make sure your local Ollama service is active.
2. Launch the Streamlit server:
   ```bash
   streamlit run app/main.py --server.port 8502
   ```
3. Open your browser and navigate to `http://localhost:8502`.

---

## ⚠️ Limitations
- **Model Size vs. Quality**: Uses a lightweight 3-billion parameter model (`llama3.2:3b`) to ensure smooth local inference on consumer hardware. Response quality and reasoning capability may be lower than larger, cloud-hosted models (e.g., GPT-4).
- **Scope**: Designed for single-document analysis per session.
- **Persistence**: FAISS indices and document chunks do not persist across multiple user sessions; reloading the application resets the workspace state.
